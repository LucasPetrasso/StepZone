# StepZone

A **StepZone** é uma loja virtual moderna desenvolvida com **HTML, CSS e JavaScript**, criada com o objetivo de colocar em prática conceitos fundamentais de desenvolvimento Front-End.

O projeto simula uma experiência completa de compra, permitindo visualizar produtos, filtrá-los por categoria, consultar detalhes, adicionar itens ao carrinho, alterar quantidades e finalizar uma compra de forma simulada.

## Funcionalidades

-  Página inicial com apresentação da loja
-  Catálogo de produtos
-  Filtro de produtos por categoria
-  Página de detalhes dos produtos
-  Carrinho de compras funcional
-  Aumento da quantidade de produtos
-  Redução da quantidade de produtos
-  Remoção de produtos do carrinho
-  Cálculo automático de subtotal, frete e valor total
-  Contador de itens no carrinho
-  Formulário de checkout
-  Simulação de finalização do pedido
-  Geração de número de pedido
-  Menu responsivo para dispositivos móveis
-  Navegação entre seções simulando uma SPA
-  Layout responsivo para diferentes tamanhos de tela

## Tecnologias utilizadas

```text

   ↓
Filtro por categoria
   ↓
Detalhes do produto
   ↓
Adicionar ao carrinho
   ↓
Carrinho
   ↓
Alterar quantidade / remover produtos
   ↓

   ↓

   ↓
Página de sucesso
